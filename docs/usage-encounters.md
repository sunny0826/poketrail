# 遭遇规则与队列

[中文](usage-encounters.md) · [English](usage-encounters.en.md)

[返回使用指南](usage.md#探索与捕捉)。

捕获、赠送领取或进化获得过的形态都登记为曾获得，并连同其全部祖先一起退出新遭遇池，进化和重启不恢复；战败、撤退、捕捉失败或放弃仍可重遇。领取初始伙伴后，关都的普通遭遇从 73 种变为 72 种。地区没有剩余候选时，菜单顶部横幅提示“本地区暂无新遭遇 · 可换地区”，不扣探索步；换到有候选的地区且余额足够即遭遇。五个地区都没有候选时提示“暂无新的普通宝可梦”，计步和培养照常。

已有遭遇可稍后再战，期间继续走路生成后续场，按遭遇顺序处理，最多保留 32 场（含当前场）。满队列或没有可选物种时仍积累探索步；确认结果只领取已排队的下一场，不立即用积累步数补位，因此原地连续战斗会逐场减少待战数。继续走路或切换地区时，有空位和候选即可用保留的探索步补充遭遇；同种不会重复排队。首页显示“遭遇3”，主菜单顶部横幅显示“继续遭遇3”。数字只计未开始对战的场次，开始对战后减一；当前场结束后确认结果即可领取下一场。没有遭遇时不显示数量，横幅改为显示距下次遭遇的步数；投球时仍显示“继续捕捉”。

菜单“地区”按世代排两页，选中项预览场景；切换只影响后续新建场。每场开始对战时由当前携带的伙伴出战，包括先前排队的遭遇；开战前切换或进化后，新携带者会上场。战斗中（含暂停）不能切换或进化，培养仍归实际携带者。战败或撤退不丢伙伴。精灵球不限量。首页和“记录”中永久首捕卡格的球图标右侧显示捕获种数：同种计一次，赠送和进化不增加，已捕获形态进化后仍计入。
