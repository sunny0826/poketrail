# 遭遇规则与队列

[中文](usage-encounters.md) · [English](usage-encounters.en.md)

[返回使用指南](usage.md#探索与捕捉)。

捕获、赠送领取或进化获得过的形态都登记为曾获得，并连同其全部祖先一起退出新遭遇池，进化和重启不恢复；战败、撤退、捕捉失败或放弃仍可重遇。领取初始伙伴后，关都的普通遭遇从 73 种变为 72 种。地区没有剩余候选时，“资源与数据”提示“本地区暂无新遭遇 · 可换地区”，不扣探索步；换到有候选的地区且余额足够即遭遇。五个地区都没有候选时提示“暂无新的普通宝可梦”，计步和培养照常。

已有遭遇可稍后再战，期间继续走路生成后续场，按遭遇顺序处理，最多保留 32 场（含当前场）。满队列或没有可选物种时仍积累探索步，有空位和候选后再建场；同种不会重复排队。首页与“资源与数据”显示“遭遇3”，主菜单显示“继续遭遇3”。数字只计未开始对战的场次，开始对战后减一；当前场结束后确认结果即可领取下一场。没有遭遇时不显示数量，主菜单为“暂无遭遇”；投球时仍显示“继续捕捉”。

菜单“选择地区”按世代排两页，选中项预览场景；切换只影响后续新建场。切换伙伴或进化也不会改变已保存场的伙伴快照，培养仍归实际携带者。战败或撤退不丢伙伴。精灵球不限量。首页和“资源与数据”的球图标右侧显示捕获种数：同种计一次，赠送和进化不增加，已捕获形态进化后仍计入。
