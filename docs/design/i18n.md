# 中英文界面与语言存档

操作入口见[使用指南](../usage.md#语言设置)。语言只改变展示，不改变遭遇、培养、进化、日期、随机数或捕获规则。

## 状态和提交

`locale.hpp` 定义 `Language { Chinese=0, English=1 }`。`Save.language` 是持久语言的唯一来源，`Engine::selectLanguage` 使用现有 `stage/submit` 事务；同语言不写入，已有 pending 时拒绝新选择。活动战斗、投球和待确认校时沿用安全限制。

提交成功后，Runtime 从 Engine 读取已生效语言；保存失败时保持原语言并重试同一候选。`submit()` 可能先公布语言，再因补存步数失败，所以显示依据语言公开值，不依据最后返回码。写后确认失败不保证磁盘仍是旧语言，重启按有效槽恢复。

`Engine::language()` 在启动提交失败时只公开已校验旧档的语言，不公开其他候选字段；普通语言提交失败仍返回旧公开语言。无有效存档且无 pending 时，Runtime 可以持有本次临时选择。加载恢复后重新跟随存档，不自动回写临时语言。

`ScreenState.language` 是绘制投影，`LanguagePersistence` 区分 `Saved` 与 `SessionOnly`。RAM-only 测试仍经 Engine 修改，只标为 SessionOnly。页面、图鉴、收藏状态回调和模拟器外框使用同一 Runtime 语言，不使用进程全局设置。

## 页面和文字

“语言 / Language”入口位于主菜单 index 8、首次日期引导 index 3、错误页 index 2。语言页有中文、English、返回三项，当前生效语言带标记；顶部返回和返回项回到原入口及选中项。待保存时锁定新选择，存储不可用时显示“仅本次生效 / Session only”。

`ui_messages.inc` 汇总 `ui_messages_test.inc`、`ui_messages_game.inc` 与 `ui_messages_system.inc`，按测试控制台、玩法页面和系统提示成对保存中文和英文，通过 `i18n::Text` 与 `text(Language, Text)` 查询。格式串的参数类型和顺序必须一致；新增句子须同步两列与格式验证。协议键、串口诊断、文件路径和数字格式保持稳定。

页面通过 `pokedex_text` 的语言参数化接口取名称和属性。中文复用现有 Sprite 元数据；英文表由 [build_pokedex.py](../../tools/build_pokedex.py) 从固定 PokeAPI CSV 生成，覆盖 #1–649。保留正式名称的性别符号、空格和撇号，不使用英文 slug 代替名称。动画结构和像素数据不因翻译重生成。

语言变化只标记文字重绘；图鉴的 `setLanguage` 使文字缓存失效，不调用 `begin()` 重置播放。长句按实际字体宽度和圆屏位置排版，操作、错误和进化确认不得裁去关键语义。

## 迁移与隔离

schema8 只在 schema7 payload 尾部增加一字节语言，ruleVersion 仍为 3。schema1–7 字节布局保持原样，旧格式只允许中文；schema8 的其他语言值视为损坏。7→8 默认中文，不重跑地区迁移。完整规则见[存档迁移](save-migration.md#schema7-迁移到-schema8)。

测试快照继承语言；空白测试档默认中文；固定测试场景保留当前测试语言。测试退出重新加载正式档，不向正式档复制语言。存储错误下的临时选择不触发格式化或建立新档。

## 验证边界

`test-pokedex` 独立解析固定来源，逐项核对 649 个英文名称及属性和生成物。玩法与存储测试覆盖语言编码、CRC 正确但非法语言、迁移、冻结候选、启动失败与测试隔离。真实 Runtime 渲染和 SDL E2E 检查输入、文本、截图、真实文件与新进程恢复，场景入口见[覆盖矩阵](simulator-e2e-coverage.md)。

交付前按[验证说明](../verification.md#每次任务的-e2e-验收要求)运行相关专项与定向 E2E；存档格式、迁移等命中全量触发条件的改动须运行全量。纯文档改动只核对内容、链接及格式。主机结果不证明实体圆屏可读性、Flash 写入时延或物理断电恢复；这些仍需 C152 验证。
