# 进化规则与普通遭遇

本文是[步行培养与存档契约](walking-progression.md)的进化与遭遇目录部分；培养账户、页面操作和存档迁移仍见该契约。

数据固定为 PokeAPI 提交 `f38eb24b70f8462976154f534e79bf2bdd7af847`，全国编号 #1–649、五个世代共 320 条进化边。旧 122 条边及费用保持不变：关都 72 条使用 `version_group_id=1,is_default=1`，城都 50 条使用 `version_group_id=3,is_default=1`。新增 198 条包括 191 条目标为 #252–649 的边，以及 7 条新宝宝到旧物种的边。

新增边从固定 CSV 选择无地区限制、来源与目标均匹配默认形态的唯一 `is_default=1` 记录，保留记录 ID、CSV 行号和 versionGroup；缺失或多条匹配均报错。versionGroup 表示采用的记录版本，不表示该进化首次出现的游戏；这些默认记录混合多个游戏版本，不是对《黑／白》历史进化条件的完整复刻。新增宝宝父关系不会取消旧普通资格，也不会改变已冻结的旧进化费用。

52 条关都等级边的费用是 `500 × (目标进化等级 − 来源进入等级)`。根进入等级为 1；有等级入边的来源用该入边等级。20 条道具／交换边统一 10000，原等级保持 null，明确为本游戏改编。城都新增边沿用同一条等级公式，共 31 条等级边；亲密度、昼夜、携带道具／交换等特殊改编共 19 条，统一 10000 步，原等级只在有等级时保留。太阳／月亮伊布由玩家选择分支，无畏小子同样三选一，不使用 RTC 或攻防数值。新增边沿用相同改编：纯等级条件按等级差计算，其余条件统一 10000；来源进入等级按父链依赖求解，不能假定父编号更小。旧费用从冻结目录保留。土居忍士 → 铁面忍者采用等级费用，土居忍士 → 脱壳忍者作为 10000 步的独立一换一分支，不额外赠送另一只。若出现特殊入边之后再接等级边，必须显式给出进入等级。例：绿毛虫 3000 后铁甲蛹再 1500；合法已有迷你龙 14500 后哈克龙再 12500；菊草叶 7500 后月桂叶再 8000。

完整关都 72 条边冻结在[evolution-gen1.json](../../assets/evolution-gen1.json)，旧 122 条边与费用冻结在[evolution-251.json](../../assets/evolution-251.json)。当前[build_evolution_rules.py](../../tools/build_evolution_rules.py)读取固定 CSV 和旧快照，生成 320 条边与 `parents` 到[evolution-649.json](../../assets/evolution-649.json)，同时核对旧快照与费用未漂移。[来源清单](../../assets/evolution-source/manifest.json)固定三份 CSV 及哈希；[build_sprites.py](../../tools/build_sprites.py)只读取[sprite-scales.json](../../assets/sprite-scales.json)的显式缩放，不再读取父母关系，避免新增父母改变 Gen1 画面。

普通资格是[遭遇目录](../../assets/adventure-649.json)的显式 `ordinaryRoots`。原关都 73 种、城都 51 种资格保持不变，新 #252–649 则从目录内无父形态中选择普通种。神兽、幻兽按固定 species CSV 的 `is_legendary`／`is_mythical` 排入保留集合；原 #144–151、#243–245、#249–251 与 #246 的活动保留继续有效。每种都必须属于普通、保留或进化目标之一。

路线资格按官方属性推导，双属性可以属于多条路线。目录可达不表示单份新档能收齐：伊布、无畏小子和土居忍士的一次捕获只能选择一条分支。伊布现在可选水、雷、火、太阳、月亮、叶、冰伊布，均为 10000 步。小火龙、鲤鱼王、墨海马不因外形或名称被排除。

[遭遇目录入口](../../assets/adventure-649.json)的 `routeTypes` 是路线资格唯一来源，每种属性只归一条路线：森林为草、虫、毒、妖精、一般、格斗；海边为水、冰、飞行、电；洞窟为火、岩石、地面、钢、恶、幽灵、超能力、龙。`speciesFiles` 引用[物种配置](../../assets/adventure-routes)，文件只声明编号、名称、稀有度与权重，文件名和手写 `routes` 不再参与资格。生成器读取 Gen1–Gen5 图鉴的 `pokemon_type_name`，按位或双属性得到掩码，核对 649 种都非空，并合并排序、校验稀有度和正权重，以及每位物种都有获取归属（普通、保留或进化目标）。schema 1–4 的旧掩码冻结在原基线目录并生成到 `route_masks_v4_generated.hpp`；schema 5 起运行时只读新掩码。完整 649 目录供图鉴使用，旧档 ID 按其 schema 的 151／251 上限校验；普通抽样只允许该路线内的显式普通根且 `captureCounts[id-1] == 0`，再按现有权重抽样，当前未拥有者仍为三倍权重。资格不依赖 `owned`，所以进化后的已捕获来源不会回池。初始赠送的捕获次数为0，仍有唯一一次捕获机会。

路线池耗尽时返回0，Engine不消耗探索步、不发遭遇ID、不创建空物种。换到仍有候选的路线后，若探索余额达到已保存的当前目标（200–500 步），即可生成下一场。全部普通种捕获后仍可计步和培养，菜单说明当前状态。不能把排除物种的权重改为0来绕过目录校验。已合法拥有的高级形态和活动种继续可浏览、携带、培养，迷你龙可以进化；当前没有活动入口或发放。
