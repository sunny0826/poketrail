# 进化动画与图鉴预览

本文维护进化的表现层契约。培养消费、拥有资格和可操作阶段见[步行培养与存档契约](walking-progression.md)，操作入口见[使用指南](../usage.md)，检查范围见[验证说明](../verification.md)。

## 保存后播放

真实进化保存成功后，由 Runtime 播放 4800ms 的动画，随后打开目标详情：

| 阶段 | 时长 |
| --- | ---: |
| 原形态蓄光 | 800ms |
| 两种轮廓交替 | 2000ms |
| 闪光 | 400ms |
| 新形态展示 | 1600ms |

动画只持有 RAM 中的来源、目标和起始时刻，不修改 Engine 或存档。失败重试只在已保存的进化回执与原请求匹配时开始动画；仅步数保存成功不算进化完成。播放期间继续采样和归账，存储错误优先显示。重启直接使用已保存伙伴，不补播、不再次消费。

## 图鉴预览

自由图鉴对存在进化边的物种显示“预览进化”，单目标直接播放，伊布先选择目标。预览只读取目录目标，不受拥有、培养余额或存储可用性限制；不调用进化命令，不覆盖待重试的真实进化请求。

所有阶段标记“进化预览”，结束或再次跳过返回原图鉴条目。预览期间仍正常采样、归账和执行必要保存；预览自身不写存档，待处理的存储错误在退出自由图鉴后恢复显示。

## 输入与绘制

预览与真实进化复用时间线、渲染和输入释放门，均按 40ms 调度重绘并保持亮屏。一次新的按键或轻触跳到新形态，展示期间再操作即进入目标详情或返回原图鉴条目。确认或跳过的按住状态不能穿透到下一页；自然结束后立即接受新输入。

原始素材帧时长和整数缩放保留，跳过展示不会重启物种自身的动画。40ms 是调度间隔，实体设备的连续画面和输入时延仍需实测。
