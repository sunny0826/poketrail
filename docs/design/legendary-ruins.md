# 传说遗迹

传说遗迹是 issue #1 的一次性解谜加常驻首领挑战。它复用普通遭遇的战斗、投球、捕获动画与保存事务，只新增数据目录、活动状态和页面。

## 玩家流程

1. 在三条路线任意顺序完成三条线索任务。
2. 按线索标出的次序排列路线。正确顺序为海边 → 森林 → 洞窟（线索页分别标为第 1、2、3 位）。排错不扣球、不扣步、不解锁，并指出首个冲突位置。
3. 解谜成功后永久开放 11 个目标：144、145、146、150、151、243、244、245、249、250、251。
4. 选择目标后挑战首领；胜利进入现有投球流程。每种只能成功捕获一次。

遗迹只需解锁一次。之后不再要求线索或排列路线；已捕获的目标可以重打首领，但胜利后跳过投球与全部奖励。完成状态从 `captureCounts` 派生，不保存第二套完成位图。

## 固定目录

线索（[ruins_catalog.hpp](../../firmware/apps/20_pokedex/ruins_catalog.hpp)）：

| 线索 | 路线 | 对手 | 任务 |
| --- | --- | --- | --- |
| 森林 | Forest | 10 | 胜利 |
| 海边 | Coast | 54 | 胜利且至少 2 次 Perfect |

三条线索战斗都使用默认参数：3/3 HP、12 拍、1500ms、±180/±70ms、交替攻防、guard 0。胜利只写入对应线索位，不进入投球，不发捕获奖励。三条线索与正确顺序都是固定数据，不使用随机池，也不依赖 RTC、门票或总步数。

## 状态与事务

`Save` 只新增既有 schema3 活动块中的字段，不改变编码形状：

- `ruins.clueMask`：bit 0/1/2 对应森林/海边/洞窟。
- `ruins.unlocked`：只能在 `clueMask == 0b111` 之后置位，且单调。
- `ruins.lastTarget`：0 或 11 个目标之一；切换只在该字段写入。
- 当前活动遭遇仍在 `Encounter` 中：`origin = Ruins`，`species`/`opponent` 与目录一致，ID、seed、投球记录和普通流程共用同一结构。
- `activityEncounterCount` 与 `nextEncounterId` 共同保持探索账：活动 ID 占据同一序列但不扣 5000 步。

Engine 独占以下命令，页面只读：

| 命令 | 前置 | 效果 |
| --- | --- | --- |
| `beginRuinsClue` | 未解锁、线索未获得、Walking | 创建固定线索遭遇，不扣探索步 |
| `solveRuinsOrder` | 三条线索齐、Walking | 正确则解锁一次；错误只返回首个冲突位 |
| `selectRuinsTarget` | 已解锁、无活动遭遇 | 幂等写入 `lastTarget`，不创建遭遇 |
| `beginRuinsBoss` | 已解锁、有目标、Walking | 创建首领遭遇 |
| `retryRuinsActivity` | 结果已关闭且可重试 | 新 ID/seed 重建当前阶段 |
| `acknowledgeActivityResult` | 活动结果已关闭 | 只清理当前遭遇，不走普通 `createEncounter` |

普通 `acknowledgeResult` 拒绝活动遭遇，避免把活动结果当作普通场重新抽签。首领或投球失败、撤退、放弃只关闭当前遭遇；线索、解锁与目标保留。保存失败继续冻结同一 candidate，提交成功前不显示奖励。

## 校验不变量

`validate()` 拒绝以下状态：

- 线索位超出 3 位；`unlocked` 但线索不齐；`lastTarget` 不是目录目标。
- 活动遭遇的 `origin` 不是 Ordinary/Ruins（龙穴留给 R2），或活动 ID 落在 legacy 边界内。
- 线索遭遇的 `species`/`opponent` 不等于目录对手、路线不符、已解锁、使用过球或进入投球阶段。
- 首领遭遇的 `species`/`opponent` 不一致、未解锁、与 `lastTarget` 不符。
- `RuinsClue`/`RuinsCleared` 结果缺线索位、缺捕获记录或使用过球。
- 当前线索场的线索位与终态不一致：`RuinsClue` 必须已置位本场路线，未结算、`Lost`、`Retreated` 不得已置位；其他路线的已获得位仍合法。
- schema1/2 带活动字段；活动计数超出 `nextEncounterId - legacyChargedCount - voidedLegacyCount`。

线索战对手（10/54/74）是普通物种，可能在普通流程中已被捕获。启动时的“已捕获即释放”守卫只对普通遭遇和处于投球阶段的首领生效，不会误关线索战；重启后同一线索遭遇恢复为 `EncounterReady`。

## 页面

主菜单第三页新增“传说遗迹”。页面只保留必要文案：

| 页面 | 内容 |
| --- | --- |
| 遗迹 | 三条线索状态、线索数或当前目标参数；三个动作 |
| 线索 | 三条线索的获得状态、任务提示；已获得的行标出它在路线顺序中的第 1/2/3 位 |
| 排列路线 | 三个顺序槽、当前选择位与冲突位；提示按线索标出的次序填写 |
| 目标 | 11 个目标分页列出，标记“可挑战/当前/已完成”文字，不只靠颜色 |
| 首领 | 目标缩略图、实际生命、节拍、节奏与判定窗口 |
| 结果 | 线索获得/未获得、首领失败/逃走/撤退、已完成无奖励；失败提供“重试本阶段” |

首领详情与战斗页读取 `BattleSpec` 的实际值。血条沿用 R0 的 1/2/3 段与大于 3 的 49px 轨道。实体按键、触摸、释放门、暂停、熄屏唤醒和零球等待沿用普通流程。
