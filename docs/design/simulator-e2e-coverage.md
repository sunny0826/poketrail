# 模拟器 E2E 覆盖矩阵

测试结构、确定性与证据格式见[模拟器 E2E](simulator-e2e.md)。新功能新增场景或断言时同步更新本表。

当前默认全量注册 45 场：P0 24 场、P1 21 场。`--suite core` 仅运行 P0。场景名称与分组 ID 以 [runner 的 `CASES`](../../scripts/run_simulator_e2e.py) 为准；ID 保留原编号，不代表场景数量。下表描述剩余源码中的覆盖，不是本次执行通过记录。

| ID／起点 | 场景 | 核心断言 |
| --- | --- | --- |
| P0-02／N、F | capture、battle-fixed、capture-slow-save、battle-cues | 新档引导、走路、对战、捕获与确认；赠送不计捕获，真实捕获计一种，图鉴／伙伴／首捕入口可达，未知日期记录和下一场在重启后保留，奖励不重复。`battle-fixed` 重放独立的固定时刻与方向输入，不根据提示选键，验证能获胜。`battle-cues` 检查倒计时可见且按键不伤血／不振动、提示圈指向与按键判定一致、假动作换侧、必杀耗能、暂停恢复及剩余投球次数显示。`capture-slow-save` 注入 5000ms 逻辑写盘延迟后仍从飞行开始，捕获在新进程恢复；动画不再扣次数或发奖励 |
| P0-03／F | throws、aim | 两次提前松手分别消耗一次机会，第二次逃脱，无捕获且不扣无限球库存；新场次数归零。空等、轻触、顶边点击不消耗，左键仍按住时短右键／短触摸可取消；长触摸提前释放只记一次 Miss，重启恢复剩余一次且空等不再扣次数 |
| P0-04／F | retry-before/after/readback | 写前、写后和回读失败均不提前发布奖励或播放捕获动画；重试保留原投球结果，按住重试不能顺带确认结果；真实存档及新进程只保留一次捕获 |
| P0-05／F | progression | 只有携带者获步；携带页显示物种、培养步、费用和切换入口；首页／携带页进化取消返回原入口。切换失败不换人，重试后刷新；进化失败不扣费，其间预览其他来源不覆盖待重试进化；重试成功只扣来源 7500 步，目标使用自己的 200 步历史账户。两次新输入分别提前显示目标、进入详情，持有及释放不穿透；后续步数归目标，进化不计捕获，新进程恢复携带者和账户且不重扣 |
| P0-06／F | target-owned | 目标已有时显示拒绝原因，拥有、培养、探索、捕获及日期账户保持不变 |
| P0-07／F、X | storage | 有效槽加截断槽可恢复；双坏、未来版本和目录锁冲突拒绝启动，受保护存档及时钟文件不变 |
| P0-08／F | crash-pause/write/partial | 暂停持久化、完整写后报错、部分写入三种边界真正 SIGKILL；新进程按实际落盘状态恢复原遭遇或捕获结果，不丢已保存账户、不重复奖励 |
| P0-17／N、F | language、language-retry-before/after/readback | 引导第二页触摸切英文、英文选伙伴及首页文字可读；返回恢复来源，切中／英文后新进程保留选择。三类保存失败继续显示原语言并锁定候选，重试发布原选择且账户不变；独立核对真实槽 CRC 与语言 |
| P0-18／N、X | startup-new、startup-corrupt | 开机画面保持最短展示时段后自动退出；跨页持有双键／触摸及释放不穿透，新输入可操作。新档选伙伴、实际走路并保存，新进程冷启动恢复账户；损坏档进入错误页后仍可开图鉴，存档与时钟文件哈希不变 |
| P0-19／F | encounter-history-evolution、encounter-history-branches、encounter-history-pending | 赠送种子经进化失败／重试后永久排除来源，保留来源 500 步；全池耗尽不扣探索步且继续培养，中英文提示与新进程一致。稀疏雷丘／战舞郎历史排除未登记祖先，关都未获得的格斗旁支仍能实际遭遇；合法旧在途来源仍可捕获一次，重启不重奖，下一场排除来源 |
| P1-09／F | isolation | 单目标与伊布分支预览返回原图鉴条目；练习的暂停、对战、投球、短按取消与退出不改正式拥有、培养、探索、捕获及日期账户 |
| P1-10／N | clock、capture-clock | 未知日期步数与捕获不回填；UI 校时后新步可信，新进程恢复 UTC、时区、日期桶和各账户，并计入离线时间 |
| P1-11／F | midnight | 走路跨日归档，UI 回拨一天后新日桶为空且旧账目保留；离线一小时后新进程恢复日期与账户 |
| P1-12／旧F | migration、migration-activity、migration-rule2、migration-schema6 | rule1 旧在途零球仍可双键退出；旧活动场退休不丢累计与探索余额；rule2 升级 rule3 后可继续投球、走路建场。schema6 实际字节迁关都，海边在途场和森林历史记录分别保留；捕获后新记录显示关都，最近捕捉能读新旧地区，新进程恢复 |
| P1-13／F | lifecycle-sleep/close-save/close-clock/throw-focus/throw-close | 闲置熄屏、触摸不唤醒、P 唤醒；宿主焦点事件不干扰脚本，主动失焦停步并释放输入。蓄力中失焦或关闭会结算一投；存档／时钟文件关闭保存失败保留窗口，故障解除后能退出 |
| P1-14／F | edges | 伙伴列表第三行外点击无效，真实可见边缘点击打开正确伙伴；列表触摸翻页与末页返回可用；图鉴左滑前进、右滑返回、短拖不切换，长名图鉴条目、伊布末分支及列表返回可达；保留真实截图供视觉审阅 |
| P1-16／N、F | regions、region-exhausted | 经菜单选神奥后只遇 #387–493，结果与记录显示神奥，新进程保留地区与捕获。神奥捕完后走路不扣探索步，提示可换地区；切合众后已有余额立即生成 #494–649 遭遇，新进程恢复 |
| P1-18／旧F、X | language-schema7、language-corrupt/future | schema7 冻结字节升级默认中文，地区与培养账户不丢，选英文后新进程恢复；损坏／未来版本槽可用会话英文及英文图鉴，原文件哈希不变，重启回中文 |
| P1-19／F、N | language-pages、language-capture | 英文特殊字符名称和属性、长名、列表末页、时钟及进化确认可读可操作；真实进化后新进程保持英文与来源扣款。英文完整捕获、结果、图鉴、首捕卡与重启保留语言及唯一捕获 |

N 为新档，F 为合法 fixture，X 为预制坏文件；fixture 不证明其已有培养步来自真实走路。公共场景入口等待启动页完成后再执行旅程；`startup-*` 直接在启动期间注入 SDL 输入。

本轮删除 `journey`、`startup-existing`、`evolution-retry` 三个重复场景：相应普通路径分别由 `capture`、`startup-new` 的新进程恢复和 `progression` 承担。原生 OS 键鼠路径尚未接入默认 runner，不计入 45 场。

预览与练习检查正式业务账户不变，不约束后台 checkpoint 的写入次数。时钟重启另比较 UTC（1 秒容差）、时区、日桶、历史与总账。截图供问题定位和人工读图，不要求整屏哈希或私有 revision 精确相同；历史验收目录继续保留，不能替代本轮执行结果。
