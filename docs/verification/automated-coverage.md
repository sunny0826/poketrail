`test` 检查交替帧、整数缩放、来源替换及损坏来源恢复后的实际颜色与透明像素，不再统计 zlib 调用或约束缓存替换顺序。这不能证明设备解码耗时、帧率或动态内存峰值；ESP32 的 PSRAM 使用仍须实测。

历史布局和来源须按版本检查，旧 122 条进化边、251 种素材的结果不代表当前目录。主机 ABI 的 `sizeof`、编码缓冲容量与构建静态 RAM 均不能代替设备动态内存实测。
