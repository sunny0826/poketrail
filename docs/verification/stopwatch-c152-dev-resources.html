M5Stack StopWatch 二次开发资源汇总

素材整理：快龙 · 引用编号见文末来源

一句话结论想在 StopWatch 上加自己的功能，优先走出厂固件的 ESP-IDF 路线：在 main/apps/ 里放一个独立 app，launcher、HAL 和出厂功能都能直接接着用。 [2][8][9]

硬件概况

主控是 ESP32-S3R8，16MB Flash、8MB PSRAM，带 2.4GHz Wi-Fi，SKU 为 C152。 [1][8]

屏幕是 1.75 英寸 466×466 圆形 AMOLED 触摸屏，显示驱动 CO5300，触摸芯片 CST820。表身另有可编程按键和振动马达。 [1]

音频用 ES8311，配 IMU、RTC RX8130CE、M5PM1 电源管理加 M5IOE1 IO 扩展，电池 450mAh。 [1]

官方文档页提供尺寸 PDF、结构文件和各芯片 datasheet。结构文件可用于外壳设计。 [1]

先确认硬件版本。v1.0 于 2026-05-22 发布，部分批次的贴纸把 5V IN 引脚误标成 BAT，这个脚严禁接电池。v1.0.1（2026-08-27）已把该脚改成真正的 BAT。 [1]

推荐路径与上手步骤

推荐出厂固件的 ESP-IDF 路线。固件栈是 ESP-IDF + LVGL + Mooncake（应用框架），新功能以独立 app 的形式放进 main/apps/，复用 launcher 与 HAL，原有功能不动。 [2][8][9]

  1. 准备环境。装 ESP-IDF v5.5.4。 [2]
  2. 拉取固件与依赖。克隆 M5StopWatch-UserDemo，执行 python3 ./fetch_repos.py。 [2]
  3. 先编译原版。idf.py build，通过之后再改代码。 [2]
  4. 写自己的 app。在 main/apps/ 下新建目录，照现有 app 的写法接 launcher 和 HAL；需要参考就翻出厂固件源码。 [2][8][9]
  5. 烧录验证。idf.py flash。 [2]
  6. 按需求挑参考项目。要走 BLE 连电脑，看 cc-island 的 NimBLE Nordic UART 外设加 Mac 端 Python 桥接；要联网上报数据，看 MQTT-Counter 的 Wi-Fi 配网、MQTT 同步和 NVS 持久化。 [8][9]

不想碰 C 的话，UiFlow2 有 3 个官方示例：RTC 时钟、电源管理、录音回放。 [4][5]

社区项目

cc-island

github.com/xiaoyuanzi1230/cc-island [8]

把 Claude Code / Codex 的用量做成表盘。手表当 NimBLE Nordic UART 外设，Mac 端用 Python 桥接推 JSON 过来。 [8]

仓库里的 install_firmware.sh 会自动克隆出厂固件并集成 app，加 app 的流程可以照着它走。 [8]

个人项目，0 星，仓库带 fork 标记。 [8]

M5StopWatch-MQTT-Counter

github.com/slochewie/M5StopWatch-MQTT-Counter [9]

场馆人数计数器。带 Wi-Fi AP 配网、MQTT 同步、NVS 持久化，浅睡和深睡可配置。 [9]

仓库有 architecture、mqtt、power-management 等文档，想看联网和功耗怎么处理，从这里入手比较快。 [9]

个人项目，MIT 许可。 [9]

社区玩法（X 上）

下面几条来自 X 上近一周的公开帖。帖里的仓库地址多是短链，这里只给帖子链接。

坑与注意

  • 别信 v1.0 的贴纸。5V IN 被标成 BAT，接上电池就出事；v1.0.1 才修好。 [1]
  • 下载模式要长按复位约 2 秒。烧不进去先检查这一步。 [3]
  • PlatformIO 用 board = esp32s3box。官方配置里分区表按 16MB、PSRAM 按 qio_opi 设置，别漏。 [3]
  • 官方仓库体量很小。15 星、11 fork、1 个 open issue，公开资料不多。 [2]
  • 小智用 M5Burner 直接烧。它和出厂固件分属不同仓库。 [6][7]
  • 续航和拆机。X 上有人问电池掉得快，也有人说外壳拆不开，两条都还没人回答。另外现在缺货，有渠道已下架。 [14][15][16]
  • 要摄像头得等底座。M5Stack 官方回复说，摄像头要等 StopWatch Base（底座），年底才出。 [17]

缺口

  • 官方文档和 GitHub 上没找到 ESPHome 或 Home Assistant 的专用支持。 [1][2]
  • 没有官方的 Mooncake app 开发文档。现在只能读出厂固件源码，加上 cc-island 和 MQTT-Counter 两个实例。 [2][8][9]
  • 社区资料少，官方仓库 15 星、11 fork、1 个 open issue，可参考的第三方项目目前就上面两个。 [2]
