PokeTrail 使用 Arduino、M5Unified 和 M5GFX，由 PlatformIO 构建。安装、构建、备份与烧录请从 项目 README 和 开发指南 开始；版本以 mise.toml、platformio.ini 为准。

硬件与下载模式

目标板为 C152，主控 ESP32-S3R8，16 MB Flash、8 MB PSRAM，物理圆屏为 466×466。硬件规格、原理图与芯片资料见 M5Stack 硬件文档。当前项目驱动报告 468×468，验收时仍需检查物理圆形边缘。

部分 v1.0 设备把 5V IN 误标为 BAT，不能接电池；v1.0.1 硬件已把该引脚改为真正的 BAT。接线前按 官方版本表 核对，不能只看旧贴纸。

长按电源／复位键约 2 秒，内部绿灯亮起后松开，进入下载模式。操作图见 官方 Arduino 编程页。烧录前备份目标设备的当前 Flash，并保留已有出厂备份；本项目没有首次 LittleFS 格式化入口。
