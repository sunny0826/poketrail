# 使用指南

[中文](usage.md) · **English** ([usage.en.md](usage.en.md))

## 开机

开机显示妙蛙种子动画与 PokeTrail 名称，至少持续 1.2 秒。随后按存档进入日期引导、初始伙伴选择、首页或待恢复页面；存储不可用时显示错误页。开机时按住的侧键或触摸须先松开，再进行操作。测试模式切换和普通亮屏不重复播放启动页。

## 语言设置

首页菜单第三页选择“语言 / Language”，再选“中文”或“English”。当前项有选中标记；保存成功立即生效，重启保留。返回或重选当前项不更改、不保存。

首次日期引导第二页和存储错误页也有此入口，可先切语言再校时／领取伙伴。侧键移动、双键确认或触摸选择；顶部或“返回”回原入口。

保存失败保留原语言，须先重试同次保存，期间不能切换。写入后确认失败可能已保存新语言，重启按有效档恢复。无法加载且无待保存事务时，可临时切语言浏览图鉴，标注“仅本次生效 / Session only”；不格式化或覆盖原档。存储恢复或重启后采用存档语言，仍无法加载时默认中文。

语言随当前存档保存。测试快照继承正式档语言，测试内切换不改正式档；空白测试档默认中文，RAM-only 测试只在本次运行保留。schema1–7 升级到当前 schema9 后默认中文，schema8 保留原语言；账户和捕捉历史按原迁移规则保留。

## 探索与捕捉

存储可用后，先设置日期、时间和 UTC 偏移，再从妙蛙种子、小火龙、杰尼龟中选择伙伴。可以暂不校时：累计步数和探索继续，未知日期的步数和捕捉时间不会事后回填。初始赠送和自由浏览图鉴不产生首捕卡。

五地区从一开始全部开放，新档从关都出发；各地区只遇见本世代编号内的普通宝可梦：

| 地区 | 图鉴编号 | 普通遭遇 |
| --- | --- | --- |
| 关都 | #001–151 | 73 种 |
| 城都 | #152–251 | 51 种 |
| 丰缘 | #252–386 | 63 种 |
| 神奥 | #387–493 | 38 种 |
| 合众 | #494–649 | 69 种 |

每场随机走 200–500 步后保存遭遇并轻震提醒。仅遇显式普通池；神兽、幻兽、迷你龙一家和幼基拉斯留作后续活动，当前无发放入口。地区不限制进化：关都大嘴蝠可进化为城都叉字蝠。

遭遇按顺序保留，最多 32 场（含当前场）。首页和“资源与数据”显示“遭遇3”，主菜单显示“继续遭遇3”；数量只计未开始对战的场次。候选资格、队列处理、切换地区与伙伴和球图标含义见[遭遇规则与队列](usage-encounters.md)。

当前拍的方向和时机只看收圈；底部灰点预告下一拍，不提示方向。获胜后最多投两球，成功即结束。投球只看宝可梦周围的圈收拢时松手。判定、必杀与练习规则见[对战与投球](usage-battle.md)。

## 伙伴与进化

每种最多拥有一只，一次携带一只，只有携带者获得培养步。菜单第二页的“携带伙伴”直接展示当前携带者、累计陪伴步数、可用培养步和各进化目标的费用。不可进化的目标置灰，选中时显示原因；最终形态显示“已是最终形态”。

选择“切换携带者”进入“我的伙伴”，按图鉴编号选择伙伴并在详情中携带。返回列表再返回时，会回到已刷新的携带伙伴页。该页的“返回菜单”或顶部返回会回到原菜单位置。“我的伙伴”也可从菜单第一页单独进入。

纯等级进化按目录中的等级差 ×500 步计算，初始形态从等级 1 起算；亲密度、昼夜、道具、交换等特殊条件改编为 10000 步。分支分别计费，具体费用以伙伴详情为准。达到门槛后首页伙伴名下方出现“进化”按钮，点按即进入确认；分支进化先打开伙伴详情选择目标。也可以从“我的伙伴”进入。

| 进化链 | 各阶段费用 |
| --- | --- |
| 妙蛙种子 → 妙蛙草 → 妙蛙花 | 7500，再 8000 |
| 小火龙 → 火恐龙 → 喷火龙 | 7500，再 10000 |
| 杰尼龟 → 卡咪龟 → 水箭龟 | 7500，再 10000 |
| 鲤鱼王 → 暴鲤龙 | 9500 |
| 皮卡丘 → 雷丘 | 10000 |
| 菊草叶 → 月桂叶 → 大竺葵 | 7500，再 8000 |
| 火球鼠 → 火岩鼠 → 火暴兽 | 6500，再 11000 |
| 小锯鳄 → 蓝鳄 → 大力鳄 | 8500，再 6000 |
| 波克比 → 波克基古 | 10000 |
| 无畏小子 → 战舞郎／飞腿郎／快拳郎 | 所选分支 10000 |
| 伊布 → 水／雷／火／太阳／月亮／叶／冰伊布 | 所选分支 10000 |

进化替换原形态，图鉴保留“曾经获得”。来源余额留在原物种账户，目标使用自己的账户。来源形态登记曾获得后不再进入新遭遇，剩余余额通常不能靠新捕获恢复；已在存档中的遭遇仍可完成，此时捕获恢复当前拥有并复用原余额。伊布七分支与无畏小子三分支见上表；每份存档对每种来源只能选一条，在伙伴详情选择，不参考 RTC 昼夜或攻防数值。

土居忍士可以选择铁面忍者或脱壳忍者。脱壳忍者分支花费 10000 培养步并替换土居忍士，不同时赠送铁面忍者；账户规则与其他进化相同。

目标已经拥有时整笔操作被拒绝，双方和步数不变。进化不扣总步、探索步或球，不增加捕捉次数或首捕卡。切换和进化限普通探索或待战遭遇；有待重试存档、待确认校时或正在对战／投球时，先完成当前流程。

确认并保存成功后播放约 5 秒的进化动画，随后打开新伙伴详情。松开确认键后，任一侧键或轻触可跳到新形态，再次操作进入详情；跳过不撤销进化。保存失败显示错误，同次进化重试成功后才播放；动画中重启保留新伙伴，不重播、不重复扣步。动画阶段见[进化动画](design/evolution-animation.md)。

图鉴底部“预览进化”播放该物种的进化动画，分支可选。无需拥有或培养步，新档和存储错误时也可用；不改变伙伴、培养余额或捕捉记录。结束或跳过后回原条目；无后续进化时不显示入口。

## 页面操作

首页显示携带伙伴、地区场景和今日步数。日期可信但记录不完整时显示“今日已记录”，日期未知或异常时显示“今日 --”，累计步数仍保留。菜单“资源与数据 → 日期与时间”设置正确时间并“保存并校时”，成功后恢复今日统计；未知期间只保留累计数。“资源与数据”汇总步数、地区、捕获种数、培养和遭遇提示。

点按任一侧键或轻触首页打开菜单，这次动作不会同时导航或确认。全部松手后再操作。菜单第四页“返回探索”或轻触顶部均可返回首页。

普通菜单左键松开上移、右键松开下移；双键可先后按下，重叠即确认，之后须全松开。触摸按钮在松手时执行，横滑不激活。多页菜单可横滑或用底部按钮翻页，记录详情也可横滑；轻触顶部返回上级。

| 页面 | 操作 |
| --- | --- |
| 对战／捕获练习 | 左键躲避、右键攻击；左右半屏触摸等价 |
| 暂停 | 触摸顶部（标题下的暂停符号）或双键按住 800 毫秒，在当前拍结束后暂停；恢复后先倒数 3、2、1 |
| 投球页 | 按住右键或触摸蓄力，松手投出；顶部区域不触发投球 |
| 练习投球 | 与投球页相同；轻触顶部结束练习。每场两次、不消耗精灵球，成功后不收入图鉴 |
| 携带伙伴 | 查看培养步与进化费用、切换携带者或选择进化目标；确认页取消回到此页 |
| 伙伴详情 | 选择携带或进化目标，进化须再次确认 |
| 进化动画 | 任一侧键或轻触跳到新形态，再次操作进入详情 |
| 记录 | 左右翻页；触摸下方返回，或选到返回后确认 |
| 校时 | 选择字段并确认编辑；左减右加，双键结束编辑，最后保存 |
| 图鉴 | 左键／右滑上一只，右键／左滑下一只；点顶部返回 |
| 图鉴互动 | 点中央伙伴：轻跳、爱心、短振动，动画继续 |
| 图鉴进化预览 | 点底部“预览进化”；任一侧键或轻触跳到新形态，再次操作返回图鉴 |
| 电源键短按 | 按下即触发：清醒时省电（下述活动流程除外）；休眠时唤醒，只点亮屏幕，不执行页面动作 |

图鉴 1～649 循环，按住不连跳，同帧双键不切换；短拖动、竖滑和长按释放不当作点击。

30 秒无操作自动省电，也可短按电源键或选菜单第三页“立即省电”。熄屏仍计步、读时钟、保存和振动提醒遭遇。无振动、存档空闲且未连 USB 主机时，主控浅睡至下次采样，侧键／触摸可提前唤醒主控；连接 USB 时只熄屏、不浅睡，以保留串口。仅短按电源键点亮屏幕，触摸、滑动及侧键均不点亮或操作页面；唤醒后全部松手再操作。完全关机不计步，双击电源键由 M5PM1 硬件关机，见[硬件说明](../README.md#硬件)。

活动中的对战、练习、投球时间线和进化动画（含图鉴预览）保持亮屏，短按电源键也不会熄屏。暂停、等待投球和校时编辑时可以熄屏，唤醒后保留状态与草稿。验收范围见[设备观察与待验事项](verification.md#设备观察与待验事项)。

长按电源键约 2 秒，内部绿灯亮起后松开，仍会进入硬件下载模式；这是设备固有行为，见 [M5Stack 下载模式说明](https://docs.m5stack.com/en/arduino/stopwatch/program)。

电量来自电压估算，充电时可能偏高；20% 及以下变红，不可用时显示“--”。

## 日期与存档

午夜只切换今日统计，累计步数、剩余探索步、伙伴和永久成就保留。捕捉册保存 649 种首捕卡、最近 32 次捕捉和各物种捕捉次数；日汇总保存最近 14 个有记录日期。每日里程碑为 1000／3000／5000 步，累计里程碑为 10000／50000／100000 步。

RTC 按 UTC 保存，历史记录保留当时偏移。同日重新校准不清空成绩；日期回拨或时间异常进入未知状态，错设未来日期须在校时中选择“修正日期”。校时先保存待确认事务，再写入并回读 RTC，最后保存确认；重启遇到未完成事务须重新确认。

LittleFS 双槽存档在安全阶段通常每 30 秒保存步数；最近 2 秒仍有步数时，延至步频停止或距上次周期保存 120 秒。遭遇、胜利、投球和成就另行提交。保存失败冻结同次结果，重试不重抽，提交成功前不显示奖励。断电可丢未保存步数；活动时间线和存储故障仍会延迟保存，120 秒并非通用丢失上限。

挂载失败显示“存储未初始化”，不会自动格式化或覆盖旧档，图鉴仍可浏览。坏档、较新版本与 I/O 错误分别提示并保留文件；一槽损坏可恢复另一有效槽。

升级保留已有账户、捕捉历史、总步和探索余额；新增物种不补发历史培养步，schema1 的培养从 0 开始。schema7 起旧路线改为世代地区，在途场可继续，历史捕捉地点保留。旧场关闭、退款、用球与版本转换规则见[迁移契约](design/save-migration.md)。

## 桌面模拟与 E2E 验证

完成[开发环境准备](development.md#环境与首次构建)并安装 SDL2 后，可在电脑上运行模拟器：

```bash
rtk proxy mise run simulate
```

键鼠操作与独立桌面存档见[桌面模拟指南](simulator.md#操作)。

维护时的完整 E2E 命令和证据要求见[验证指南](verification.md#每次任务的-e2e-验收要求)。主机通过不代表设备验收通过。

## 设备内测试模式

测试模式供开发者和维护者复现问题，不属于普通玩法；独立存档、入口与操作见[设备内测试模式](usage-test-mode.md)。测试数据不写回正式槽；进入前正常保存可更新正式档，退出加载不提交启动记录。
