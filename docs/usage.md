# 使用指南

## 探索与捕捉

存储可用后，先设置日期、时间和 UTC 偏移，再从妙蛙种子、小火龙、杰尼龟中选择伙伴。可以暂不校时：累计步数和探索继续，未知日期的步数和捕捉时间不会事后回填。初始赠送和自由浏览图鉴不产生首捕卡。

森林、海边、洞窟各有不同遭遇池。每 5000 探索步保存一场遭遇并轻震提醒，普通探索只出现第一世代的 73 种初始形态。神兽、幻兽和迷你龙一家留给后续活动，当前没有发放入口。

每种成功捕获后永久退出所有路线的遭遇池，进化和重启也不会恢复资格。战败、撤退、捕捉失败或放弃后仍可再遇见。初始赠送不算捕获，仍可捕获一次。路线捕捉完后可以换路线，额外探索步继续保留。

已有遭遇可以稍后再战，期间继续积累步数；切换路线只影响下一场。战败或撤退不丢伙伴。每 1000 总步获得一球，新档零球，走到首场已有五球。跨日不清空球和余数。

战斗双方各三格生命，交替攻击和躲避。普通窗口为 ±180 毫秒，完美窗口为 ±70 毫秒；每拍只接受第一次动作，错键、同时按两键和超时均未命中，最多六轮。免费练习不消耗遭遇机会。

胜利后每场最多两球，成功即结束。准备不扣球，投出或超时才消耗一球。普通宝可梦的普通／漂亮／完美概率为 55%／70%／85%，稀有为 30%／45%／60%，错过窗口为 0%。完美也可能失败。

零球时可保留胜利结果，回首页走路获得球后再返回同场，也可以确认放弃捕捉。

## 伙伴与进化

每种最多拥有一只，一次携带一只，只有携带者获得培养步。“我的伙伴”按图鉴编号列出当前拥有者，可切换携带者、查看余额和进化条件。

等级进化按原等级差 ×500 步计算，初始形态从等级 1 起算；道具与交换进化统一 10000 步。达到门槛后手动确认。

| 进化链 | 各阶段费用 |
| --- | --- |
| 妙蛙种子 → 妙蛙草 → 妙蛙花 | 7500，再 8000 |
| 小火龙 → 火恐龙 → 喷火龙 | 7500，再 10000 |
| 杰尼龟 → 卡咪龟 → 水箭龟 | 7500，再 10000 |
| 鲤鱼王 → 暴鲤龙 | 9500 |
| 皮卡丘 → 雷丘 | 10000 |
| 伊布 → 水／雷／火伊布 | 所选分支 10000 |

进化替换原形态，图鉴保留“曾经获得”。来源剩余培养步留在原物种账户，目标使用自己的账户。已捕获的来源不能重捕；尚未捕获的初始赠送伙伴仍可捕获一次并使用原账户余额。伊布只能捕获一次，因此只能选择一条分支。

目标已经拥有时整笔操作被拒绝，双方和步数不变。进化不扣总步、探索步或球，不增加捕捉次数或首捕卡。切换和进化限普通探索或待战遭遇；有待重试存档、待确认校时或正在对战／投球时，先完成当前流程。

## 页面操作

首页显示携带伙伴、路线场景和今日步数。日期可信但当日记录不完整时显示“今日已记录”；日期未知或异常时显示“今日 --”。这不代表累计步数丢失。从菜单第二页进入“日期与时间”，设置正确时间并“保存并校时”；成功后恢复今日统计，未知期间只保留累计数。

点按任一侧键打开菜单，这次按键不会同时导航或确认。全部松手后再操作。首页触摸不打开菜单，菜单第三页“返回探索”返回首页。

普通菜单左键松开后上移，右键松开后下移；双键按住有重叠即确认，可先后按下。确认后先全部松开。触摸可见按钮也能选择，多页菜单可触摸底部翻页。

| 页面 | 操作 |
| --- | --- |
| 对战／练习 | 左键躲避、右键攻击；左右半屏触摸等价 |
| 暂停 | 触摸顶部或双键按住 800 毫秒，在当前拍结束后暂停 |
| 投球菜单 | 左键切换准备／继续走路／放弃，右键确认；也可触摸 |
| 投球时间线 | 准备后先松手，再按右键或轻触投出；超时也消耗一球 |
| 伙伴详情 | 选择携带或进化目标，进化须再次确认 |
| 记录 | 左右翻页；触摸下方返回，或选到返回后确认 |
| 校时 | 选择字段并确认编辑；左减右加，双键结束编辑，最后保存 |
| 图鉴 | 左键／右滑上一只，右键／左滑下一只；点顶部返回 |
| 图鉴互动 | 点中央伙伴：轻跳、爱心、短振动，动画继续 |

图鉴 1～151 循环，按住不连跳，同帧双键不切换；短拖动、竖滑和长按释放不当作点击。

30 秒无操作后自动省电，也可从菜单第二页选择“立即省电”。屏幕休眠期间继续计步、读时钟和保存，遇见宝可梦仍振动。任意键或触摸唤醒，这次动作只唤醒，全部松手后再操作。完全关机不计步。

活动中的对战、练习和投球保持亮屏；暂停、等待投球和校时编辑时可以熄屏，唤醒后保留状态与草稿。电量来自电压估算，充电时可能偏高；20% 及以下变红，不可用时显示“--”。

## 日期与存档

午夜只切换今日统计，累计步数、剩余探索步、伙伴和永久成就保留。捕捉册保存 151 种首捕卡、最近 32 次捕捉和各物种捕捉次数；日汇总保存最近 14 个有记录日期。每日里程碑为 1000／3000／5000 步，累计里程碑为 10000／50000／100000 步。

RTC 按 UTC 保存，历史记录保留当时偏移。同日重新校准不清空成绩；日期回拨或时间异常进入未知状态，错设未来日期须在校时中选择“修正日期”。校时先保存待确认事务，再写入并回读 RTC，最后保存确认；重启遇到未完成事务须重新确认。

LittleFS 双槽存档在安全阶段每 30 秒保存普通步数，遭遇、胜利、投球和成就另行提交。保存失败冻结同次结果，重试不重新抽签，成功前不显示奖励。突然断电可能丢失未保存步数，长期存储故障不保证最多只丢 30 秒。

挂载失败显示“存储未初始化”，不会自动格式化或覆盖旧档，图鉴仍可浏览。坏档、较新版本与 I/O 错误分别提示并保留文件；一槽损坏可恢复另一有效槽。

从 schema1 升级保留伙伴、捕捉历史、总步和探索余额；培养从 0 开始，球从升级后新走的 1000 步开始获得，不补发历史球。未结束的高级／活动种遭遇关闭并退还旧规则的 500 探索步，普通根遭遇保留。已捕获过的未结算普通场关闭，不追加球、奖励或退款。细节见[迁移契约](design/walking-progression.md#schema1-迁移到-schema2)。
