# 使用指南

## 探索与捕捉

存储可用后，先设置日期、时间和 UTC 偏移，再从妙蛙种子、小火龙、杰尼龟中选择伙伴。可以暂不校时：累计步数和探索继续，未知日期的步数和捕捉时间不会事后回填。初始赠送和自由浏览图鉴不产生首捕卡。

森林、海边、洞窟各有不同遭遇池。每 5000 探索步保存一场遭遇并轻震提醒，普通探索只出现显式普通池中的初始形态：关都 73 种、城都 51 种。神兽、幻兽通过“传说遗迹”获得，迷你龙与幼基拉斯通过“龙穴试炼”获得（见下文）。

每种成功捕获后永久退出所有路线的遭遇池，进化和重启也不会恢复资格。战败、撤退、捕捉失败或放弃后仍可再遇见。初始赠送不算捕获，仍可捕获一次。路线捕捉完后可以换路线，额外探索步继续保留。

已有遭遇可以稍后再战，期间继续积累步数；切换路线只影响下一场。战败或撤退不丢伙伴。每 1000 总步获得一球，新档零球，走到首场已有五球。跨日不清空球和余数。

战斗双方各三格生命，交替攻击和躲避。普通窗口为 ±180 毫秒，完美窗口为 ±70 毫秒；每拍只接受第一次动作，错键、同时按两键和超时均未命中，最多六轮。捕获练习从菜单进入，随机出现一只宝可梦，完整走对战、两次投球与捕获动画；判定和概率与真实遭遇一致，但不消耗精灵球，成功也不收入图鉴、捕捉记录或成就。

胜利后每场最多两球，成功即结束。准备不扣球，投出或超时才消耗一球。普通宝可梦的普通／漂亮／完美概率为 55%／70%／85%，稀有为 30%／45%／60%，错过窗口为 0%。完美也可能失败。

零球时可保留胜利结果，回首页走路获得球后再返回同场，也可以确认放弃捕捉。

## 传说遗迹

主菜单第三页的“传说遗迹”是独立活动：线索战斗与首领战斗占用遭遇场，但不消耗 5000 探索步，也不要求普通路线还有未捕获的宝可梦。

先在森林、海边、洞窟各完成一次线索任务，顺序不限：森林胜利即可，海边需要至少两次完美，洞窟需要无伤胜利。三条线索战斗都使用普通的三格生命和交替攻防，胜利只给线索，不会进入投球，也不发捕获奖励。已获得的线索不能重复领取。

获得线索时，结果页和线索列表会标出这条线索的次序：海边第 1 位、森林第 2 位、洞窟第 3 位。它是线索本身给出的信息，和完成任务的先后无关。

三条线索齐后排列路线：按线索标出的次序放入海边 → 森林 → 洞窟。排错不扣球、不扣探索步、不解锁，页面指出第几位冲突；每次尝试重新输入即可。正确一次后永久解锁，重启仍保留。

解锁后可随时从 11 个传说目标中选一只挑战，之后不再需要线索或解谜。首领的生命、节拍和攻防节奏各不相同，详情页与战斗血条显示实际数值；玩家固定三格生命、12 拍、±180/±70 毫秒。胜利后沿用普通投球和捕捉动画。

首领战败、两次投球失败或撤退只会重试当前首领，线索、解锁与已选目标不变；重试使用新的遭遇编号与种子。保存失败时结果冻结，重试成功前不发放奖励。每种目标只能成功捕获一次；已捕获的目标仍可重打首领，但胜利后直接结束，不进入投球，不改变图鉴、捕获次数、首捕卡或精灵球。

## 龙穴试炼

主菜单第三页的“龙穴试炼”是独立连续战斗，与传说遗迹互不前置。入口只由全部 251 种的成功捕获总数决定：总数为 6、12、18……时两条试炼开放；0–5、7–11 等非倍数时显示还差几次。初始赠送、进化、拥有状态和步数都不计数；历史多次捕获按实际次数累加。

两条试炼分别是迷你龙（2 阶段，敌方生命 3／4，节拍 1500／1450ms）与幼基拉斯（3 阶段，敌方生命 3／4／5，节拍 1500／1450／1350ms）。玩家固定 3 格生命、每场 12 拍、±180/±70ms，阶段之间保留剩余生命。非最终阶段胜利后三选一：恢复 1 格生命（满血不可选）、后续普通窗口 +30ms 且完美 +10ms（上限 +180/+60ms）、后续每场首次漏防不扣生命（只能选一次）。选择后立即保存下一阶段。

战败或撤退只重试当前阶段，恢复该阶段开始的生命与强化，并复用同一次遭遇编号与种子。最终阶段胜利后进入普通投球；两次投球失败后只重试最终阶段，使用新的遭遇编号与种子，前置阶段和强化不重复。零球时保留胜利，走路拿到球后从龙穴入口返回同场。每种只能成功捕获一次；已捕获的目标仍可在开放窗口重打，但胜利后跳过投球与全部奖励。在 6 次捕获时完成一条后总数变为 7，另一条暂时关闭，当前结果流程不中断。

## 伙伴与进化

每种最多拥有一只，一次携带一只，只有携带者获得培养步。“我的伙伴”按图鉴编号列出当前拥有者，可切换携带者、查看余额和进化条件。

等级进化按原等级差 ×500 步计算，初始形态从等级 1 起算；亲密度、昼夜、携带道具、交换和分支进化统一 10000 步。达到门槛后手动确认。

| 进化链 | 各阶段费用 |
| --- | --- |
| 妙蛙种子 → 妙蛙草 → 妙蛙花 | 7500，再 8000 |
| 小火龙 → 火恐龙 → 喷火龙 | 7500，再 10000 |
| 杰尼龟 → 卡咪龟 → 水箭龟 | 7500，再 10000 |
| 鲤鱼王 → 暴鲤龙 | 9500 |
| 皮卡丘 → 雷丘 | 10000 |
| 菊草叶 → 月桂叶 → 大竺葵 | 7500，再 8000 |
| 火球鼠 → 火岩鼠 → 火暴兽 | 6500，再 11000 |
| 小锯鳄 → 蓝鳄 → 大力鳄 | 8500，再 6000 |
| 波克比 → 波克基古 | 10000 |
| 无畏小子 → 战舞郎／飞腿郎／快拳郎 | 所选分支 10000 |
| 伊布 → 水／雷／火／太阳／月亮伊布 | 所选分支 10000 |

进化替换原形态，图鉴保留“曾经获得”。来源剩余培养步留在原物种账户，目标使用自己的账户。已捕获的来源不能重捕；尚未捕获的初始赠送伙伴仍可捕获一次并使用原账户余额。伊布有五个可选分支（水／雷／火／太阳／月亮伊布），无畏小子有三个（战舞郎／飞腿郎／快拳郎）；每份存档对每种来源只能选择其中一条，玩家在伙伴详情选择分支，不参考 RTC 昼夜或攻防数值。

目标已经拥有时整笔操作被拒绝，双方和步数不变。进化不扣总步、探索步或球，不增加捕捉次数或首捕卡。切换和进化限普通探索或待战遭遇；有待重试存档、待确认校时或正在对战／投球时，先完成当前流程。

确认并保存成功后，播放约 5 秒的进化动画：原形态蓄光、两种轮廓交替、新形态显现，随后打开新伙伴详情。松开确认键后，按任一侧键或轻触可跳到新形态，再次操作进入详情。跳过不撤销进化。保存失败先显示错误，同一次进化重试成功后才播放；动画中重启保留已保存的新伙伴，不重播、不重复扣培养步。

图鉴底部的“预览进化”可播放该物种的进化动画，伊布可选择水、雷、火、太阳、月亮伊布，无畏小子可选择三个分支。无需拥有或积累培养步，新档和存储错误时也可使用。预览不改变伙伴、培养余额或捕捉记录；结束或跳过后返回原图鉴条目。没有后续进化的物种不显示此入口。

## 页面操作

首页显示携带伙伴、路线场景和今日步数。日期可信但当日记录不完整时显示“今日已记录”；日期未知或异常时显示“今日 --”。这不代表累计步数丢失。从主菜单进入“资源与数据”，再进入“日期与时间”，设置正确时间并“保存并校时”；成功后恢复今日统计，未知期间只保留累计数。步数、路线、精灵球、培养和遭遇提示也集中在“资源与数据”页。

点按任一侧键或轻触首页打开菜单，这次动作不会同时导航或确认。全部松手后再操作。菜单第四页“返回探索”或轻触顶部均可返回首页。

普通菜单左键松开后上移，右键松开后下移；双键按住有重叠即确认，可先后按下。确认后先全部松开。可见按钮在触摸松开后执行，按下并横滑不会激活按钮。多页菜单支持左右横滑及底部前后翻页按钮；记录详情也可横滑切换。轻触顶部返回上一级。

| 页面 | 操作 |
| --- | --- |
| 对战／捕获练习 | 左键躲避、右键攻击；左右半屏触摸等价 |
| 暂停 | 触摸顶部或双键按住 800 毫秒，在当前拍结束后暂停 |
| 投球菜单 | 左键切换准备／继续走路／放弃，右键确认；也可触摸 |
| 投球时间线 | 准备后按住右键或触摸蓄力，松手投出；超时也消耗一球 |
| 练习投球 | 与投球时间线相同；每场两次、不消耗精灵球，成功后不收入图鉴 |
| 伙伴详情 | 选择携带或进化目标，进化须再次确认 |
| 进化动画 | 任一侧键或轻触跳到新形态，再次操作进入详情 |
| 记录 | 左右翻页；触摸下方返回，或选到返回后确认 |
| 校时 | 选择字段并确认编辑；左减右加，双键结束编辑，最后保存 |
| 图鉴 | 左键／右滑上一只，右键／左滑下一只；点顶部返回 |
| 图鉴互动 | 点中央伙伴：轻跳、爱心、短振动，动画继续 |
| 图鉴进化预览 | 点底部“预览进化”；任一侧键或轻触跳到新形态，再次操作返回图鉴 |

图鉴 1～251 循环，按住不连跳，同帧双键不切换；短拖动、竖滑和长按释放不当作点击。

30 秒无操作后自动省电，也可从菜单第三页选择“立即省电”。屏幕休眠期间继续计步、读时钟和保存，遇见宝可梦仍振动。没有振动且存档不忙时，主控在下一次采样前短暂休眠，按键或触摸会提前唤醒。这次动作只点亮屏幕，全部松手后再操作。完全关机不计步。

活动中的对战、练习、投球和进化动画（含图鉴预览）保持亮屏；暂停、等待投球和校时编辑时可以熄屏，唤醒后保留状态与草稿。电量来自电压估算，充电时可能偏高；20% 及以下变红，不可用时显示“--”。

## 日期与存档

午夜只切换今日统计，累计步数、剩余探索步、伙伴和永久成就保留。捕捉册保存 251 种首捕卡、最近 32 次捕捉和各物种捕捉次数；日汇总保存最近 14 个有记录日期。每日里程碑为 1000／3000／5000 步，累计里程碑为 10000／50000／100000 步。

RTC 按 UTC 保存，历史记录保留当时偏移。同日重新校准不清空成绩；日期回拨或时间异常进入未知状态，错设未来日期须在校时中选择“修正日期”。校时先保存待确认事务，再写入并回读 RTC，最后保存确认；重启遇到未完成事务须重新确认。

LittleFS 双槽存档在安全阶段每 30 秒保存普通步数，遭遇、胜利、投球和成就另行提交。保存失败冻结同次结果，重试不重新抽签，成功前不显示奖励。突然断电可能丢失未保存步数，长期存储故障不保证最多只丢 30 秒。

挂载失败显示“存储未初始化”，不会自动格式化或覆盖旧档，图鉴仍可浏览。坏档、较新版本与 I/O 错误分别提示并保留文件；一槽损坏可恢复另一有效槽。

从 schema1 升级保留伙伴、捕捉历史、总步和探索余额；培养从 0 开始，球从升级后新走的 1000 步开始获得，不补发历史球。未结束的高级／活动种遭遇关闭并退还旧规则的 500 探索步，普通根遭遇保留。已捕获过的未结算普通场关闭，不追加球、奖励或退款。schema2 存档升级到 schema3 时保留全部已有关都字段与当前遭遇，只把 #152–251 初始化为未获得、零培养。细节见[迁移契约](design/walking-progression.md#存档迁移)。
