# 使用指南

[中文](usage.md) · **English** ([usage.en.md](usage.en.md))

## 语言设置

首页进入菜单，翻到第三页，选择“语言 / Language”，再选择“中文”或“English”。当前语言有选中标记，保存成功后立即生效，重启后保留。返回不会更改选择，重复选择当前语言不会另存一次。

首次日期引导的第二页、存储错误页也有同一入口，可在校时或领取伙伴前切换。语言页沿用侧键移动、双键确认和触摸操作，顶部或“返回”回到原入口。

保存失败时继续使用原语言，先重试原保存；在待重试期间不能再改语言。写入后确认失败时，磁盘可能已有新语言，重启会按有效存档恢复。存储无法加载且没有待保存事务时，可以临时切换并浏览图鉴，页面标注“仅本次生效 / Session only”；不会格式化或覆盖原档。存储恢复或重启后重新采用存档语言，不能恢复存档时默认中文。

语言随当前存档保存。测试快照继承正式档语言，测试内切换不改正式档；空白测试档默认中文，RAM-only 测试只在本次运行保留。schema1–7 升级为 schema8 后默认中文，账户和捕捉历史按原迁移规则保留。

## 探索与捕捉

存储可用后，先设置日期、时间和 UTC 偏移，再从妙蛙种子、小火龙、杰尼龟中选择伙伴。可以暂不校时：累计步数和探索继续，未知日期的步数和捕捉时间不会事后回填。初始赠送和自由浏览图鉴不产生首捕卡。

探索分为关都、城都、丰缘、神奥、合众五个地区，从一开始全部开放，新档从关都出发。每个地区只遇见本世代图鉴编号内的普通宝可梦：

| 地区 | 图鉴编号 | 普通遭遇 |
| --- | --- | --- |
| 关都 | #001–151 | 73 种 |
| 城都 | #152–251 | 51 种 |
| 丰缘 | #252–386 | 63 种 |
| 神奥 | #387–493 | 38 种 |
| 合众 | #494–649 | 69 种 |

每走 200–500 步（每场随机）保存一场遭遇并轻震提醒。普通探索只出现显式普通池中的物种；神兽、幻兽、迷你龙一家和幼基拉斯留给后续独立活动，当前没有发放入口。地区只限制遭遇，进化可以跨世代，例如关都的大嘴蝠可进化为城都的叉字蝠；初始伙伴仍是关都的三只。

每种成功捕获后永久退出遭遇池，进化和重启也不会恢复资格。战败、撤退、捕捉失败或放弃后仍可再遇见。初始赠送不算捕获，仍可捕获一次。某个地区捕完后，“资源与数据”页提示“本地区已捕获完 · 可换地区”，此时不消耗探索步，换到仍有宝可梦的地区后，已有余额足够即可立即遭遇；五个地区都捕完时提示“普通宝可梦已全部捕获”。

从菜单“选择地区”切换，地区按世代顺序排在两页中，选中项预览该地区场景。已有遭遇可以稍后再战，期间继续积累步数；切换地区只影响下一场。战败或撤退不丢伙伴。精灵球不限量。首页和“资源与数据”页的球图标右侧显示已捕获的宝可梦种数：同种只计一次，初始赠送和进化不增加种数，已捕获的原形态进化后仍计入。

当前拍的方向和时机只看收圈；底部灰点预告下一拍，不提示方向。获胜后最多投两球，成功即结束。判定、必杀与练习规则见[对战与投球](usage-battle.md)。

## 伙伴与进化

每种最多拥有一只，一次携带一只，只有携带者获得培养步。“我的伙伴”按图鉴编号列出当前拥有者，可切换携带者、查看余额和进化条件。

纯等级进化按目录中的等级差 ×500 步计算，初始形态从等级 1 起算；亲密度、昼夜、道具、交换等特殊条件改编为 10000 步。分支分别计费，具体费用以伙伴详情为准。达到门槛后首页伙伴名下方出现“进化”按钮，点按即进入确认；分支进化先打开伙伴详情选择目标。也可以从“我的伙伴”进入。

| 进化链 | 各阶段费用 |
| --- | --- |
| 妙蛙种子 → 妙蛙草 → 妙蛙花 | 7500，再 8000 |
| 小火龙 → 火恐龙 → 喷火龙 | 7500，再 10000 |
| 杰尼龟 → 卡咪龟 → 水箭龟 | 7500，再 10000 |
| 鲤鱼王 → 暴鲤龙 | 9500 |
| 皮卡丘 → 雷丘 | 10000 |
| 菊草叶 → 月桂叶 → 大竺葵 | 7500，再 8000 |
| 火球鼠 → 火岩鼠 → 火暴兽 | 6500，再 11000 |
| 小锯鳄 → 蓝鳄 → 大力鳄 | 8500，再 6000 |
| 波克比 → 波克基古 | 10000 |
| 无畏小子 → 战舞郎／飞腿郎／快拳郎 | 所选分支 10000 |
| 伊布 → 水／雷／火／太阳／月亮／叶／冰伊布 | 所选分支 10000 |

进化替换原形态，图鉴保留“曾经获得”。来源剩余培养步留在原物种账户，目标使用自己的账户。已捕获的来源不能重捕；尚未捕获的初始赠送伙伴仍可捕获一次并使用原账户余额。伊布有七个可选分支（水／雷／火／太阳／月亮／叶／冰伊布），无畏小子有三个（战舞郎／飞腿郎／快拳郎）；每份存档对每种来源只能选择其中一条，玩家在伙伴详情选择分支，不参考 RTC 昼夜或攻防数值。

土居忍士可以选择铁面忍者或脱壳忍者。脱壳忍者分支花费 10000 培养步并替换土居忍士，不同时赠送铁面忍者；账户规则与其他进化相同。

目标已经拥有时整笔操作被拒绝，双方和步数不变。进化不扣总步、探索步或球，不增加捕捉次数或首捕卡。切换和进化限普通探索或待战遭遇；有待重试存档、待确认校时或正在对战／投球时，先完成当前流程。

确认并保存成功后，播放约 5 秒的进化动画：原形态蓄光、两种轮廓交替、新形态显现，随后打开新伙伴详情。松开确认键后，按任一侧键或轻触可跳到新形态，再次操作进入详情。跳过不撤销进化。保存失败先显示错误，同一次进化重试成功后才播放；动画中重启保留已保存的新伙伴，不重播、不重复扣培养步。

图鉴底部的“预览进化”可播放该物种的进化动画，伊布可选择水、雷、火、太阳、月亮、叶、冰伊布，无畏小子可选择三个分支。无需拥有或积累培养步，新档和存储错误时也可使用。预览不改变伙伴、培养余额或捕捉记录；结束或跳过后返回原图鉴条目。没有后续进化的物种不显示此入口。

## 页面操作

首页显示携带伙伴、当前地区场景和今日步数。日期可信但当日记录不完整时显示“今日已记录”；日期未知或异常时显示“今日 --”。这不代表累计步数丢失。从主菜单进入“资源与数据”，再进入“日期与时间”，设置正确时间并“保存并校时”；成功后恢复今日统计，未知期间只保留累计数。步数、地区、已捕获种数、培养和遭遇提示也集中在“资源与数据”页。

点按任一侧键或轻触首页打开菜单，这次动作不会同时导航或确认。全部松手后再操作。菜单第三页“返回探索”或轻触顶部均可返回首页。

普通菜单左键松开后上移，右键松开后下移；双键按住有重叠即确认，可先后按下。确认后先全部松开。可见按钮在触摸松开后执行，按下并横滑不会激活按钮。多页菜单支持左右横滑及底部前后翻页按钮；记录详情也可横滑切换。轻触顶部返回上一级。

| 页面 | 操作 |
| --- | --- |
| 对战／捕获练习 | 左键躲避、右键攻击；左右半屏触摸等价 |
| 暂停 | 触摸顶部（标题下的暂停符号）或双键按住 800 毫秒，在当前拍结束后暂停；恢复后先倒数 3、2、1 |
| 投球页 | 按住右键或触摸蓄力，松手投出；顶部区域不触发投球 |
| 练习投球 | 与投球页相同；轻触顶部结束练习。每场两次、不消耗精灵球，成功后不收入图鉴 |
| 伙伴详情 | 选择携带或进化目标，进化须再次确认 |
| 进化动画 | 任一侧键或轻触跳到新形态，再次操作进入详情 |
| 记录 | 左右翻页；触摸下方返回，或选到返回后确认 |
| 校时 | 选择字段并确认编辑；左减右加，双键结束编辑，最后保存 |
| 图鉴 | 左键／右滑上一只，右键／左滑下一只；点顶部返回 |
| 图鉴互动 | 点中央伙伴：轻跳、爱心、短振动，动画继续 |
| 图鉴进化预览 | 点底部“预览进化”；任一侧键或轻触跳到新形态，再次操作返回图鉴 |
| 电源键短按 | 按下即触发：清醒时省电（下述活动流程除外）；休眠时唤醒，只点亮屏幕，不执行页面动作 |

图鉴 1～649 循环，按住不连跳，同帧双键不切换；短拖动、竖滑和长按释放不当作点击。

30 秒无操作后自动省电，也可短按电源键，或从菜单第三页选择“立即省电”。屏幕休眠期间继续计步、读时钟和保存，遇见宝可梦仍振动。没有振动、存档不忙且未连接 USB 主机时，主控在下一次采样前短暂浅睡，侧键或触摸会提前唤醒主控。连接 USB 主机时仍可熄屏，但不浅睡，以保持串口连接。屏幕仅能通过短按电源键唤醒；触摸、滑动及侧键不会点亮屏幕或执行页面操作。唤醒动作只点亮屏幕，全部松手后再操作。完全关机不计步。双击电源键由 M5PM1 硬件执行关机，见[硬件说明](../README.md#硬件)。

活动中的对战、练习、投球时间线和进化动画（含图鉴预览）保持亮屏，短按电源键也不会熄屏。暂停、等待投球和校时编辑时可以熄屏，唤醒后保留状态与草稿。验收范围见[设备观察与待验事项](verification.md#设备观察与待验事项)。

长按电源键约 2 秒，内部绿灯亮起后松开，仍会进入硬件下载模式；这是设备固有行为，见 [M5Stack 下载模式说明](https://docs.m5stack.com/en/arduino/stopwatch/program)。

电量来自电压估算，充电时可能偏高；20% 及以下变红，不可用时显示“--”。

## 日期与存档

午夜只切换今日统计，累计步数、剩余探索步、伙伴和永久成就保留。捕捉册保存 649 种首捕卡、最近 32 次捕捉和各物种捕捉次数；日汇总保存最近 14 个有记录日期。每日里程碑为 1000／3000／5000 步，累计里程碑为 10000／50000／100000 步。

RTC 按 UTC 保存，历史记录保留当时偏移。同日重新校准不清空成绩；日期回拨或时间异常进入未知状态，错设未来日期须在校时中选择“修正日期”。校时先保存待确认事务，再写入并回读 RTC，最后保存确认；重启遇到未完成事务须重新确认。

LittleFS 双槽存档在安全阶段通常每 30 秒保存普通步数；最近 2 秒内仍有步数事件时延后，直到步频停止或距上次周期保存达到 120 秒。遭遇、胜利、投球和成就另行提交。保存失败冻结同次结果，重试不重新抽签，成功前不显示奖励。突然断电可能丢失未保存步数；活动时间线和存储故障仍会推迟保存，120 秒不是所有情况下的数据丢失上限。

挂载失败显示“存储未初始化”，不会自动格式化或覆盖旧档，图鉴仍可浏览。坏档、较新版本与 I/O 错误分别提示并保留文件；一槽损坏可恢复另一有效槽。

升级保留已有账户、捕捉历史、总步和探索余额；新增物种不补发历史培养步，schema1 的培养从 0 开始。schema7 起旧路线改为世代地区，在途场可继续，历史捕捉地点保留。旧场关闭、退款、用球与版本转换规则见[迁移契约](design/save-migration.md)。

## 桌面模拟与 E2E 验证

完成[开发环境准备](development.md#环境与首次构建)并安装 SDL2 后，可在电脑上运行模拟器：

```bash
rtk proxy mise run simulate
```

键鼠操作与独立桌面存档见[桌面模拟指南](simulator.md#操作)。

维护时的完整 E2E 命令和证据要求见[验证指南](verification.md#每次任务的-e2e-验收要求)。主机通过不代表设备验收通过。

## 设备内测试模式

测试模式供开发者和维护者复现问题，不属于普通玩法。独立测试存档、隐藏入口、控制台操作、存储、重启与退出说明见[设备内测试模式](usage-test-mode.md)。测试数据不写回正式槽；进入前的正常保存仍可能更新正式档，退出加载不会提交启动记录。
